# V30 read-only independent official postseason scorecard

**Research only; no changes to production probabilities, simulations, stored originals or model training.**

The predeclared monitored cohort starts **October 14, 2026**. V30 retrieves all official postseason Finals through the preceding Eastern date directly from MLB's schedule endpoint, recovering a scoreless Final only through that game's official live feed with strict game ID/date/team checks. Missing/invalid original predictions remain in the full denominator and count as incorrect; no probability is invented for missing games.

Every graded original is checked against the **first GitHub commit** by reusing V28 provenance verification. The original, simple Elo and the *already frozen* V23 50/50 blend are compared on exactly the same eligible games. The 2020–2025 official postseason CSV supplies a fixed historical constant baseline for Over 4.5/5.5 and total-runs MAE. The frozen same-simulation winner-plus-Over probabilities are scored only when internally consistent; **never** use the product of winner and Over marginals. Joint-event `events_occurred` is the number of actual combined events, whereas `correct` from `metrics` is binary classification accuracy at a 50% probability threshold; these are not interchangeable.

No fitting, feature selection, calibration or winner-weight tuning is performed on 2026 outcomes. V24/V25 retrospective experiments are not promoted. Run `python -m unittest cloud.test_v30_official_cohort -v` from the project directory. The PR CI independently runs the official cohort scorecard and uploads a read-only JSON artifact. **V31 (October 26):** Pull-request CI remains fixed to **2026-10-25** for reproducibility, while scheduled daily (12:43 UTC), push, and manual runs use the current **America/New_York** date as an exclusive cutoff, so games from the current Eastern calendar day are never graded. Each execution uploads a fresh read-only JSON artifact; the model and its frozen predictions are not modified. GitHub scheduled execution is best-effort, so check run status rather than assuming a report exists. The `prospective_90pct_verified` flag is computed only when the full official cohort contains **at least 30 completed games** and the original model has correctly predicted **at least 90% of all of them**, including missing/invalid forecasts as incorrect. This is a *numerical milestone*, not statistical proof of sustained superiority. The scorecard never re-fits to 2026 outcomes.

**Interpretation:** full-cohort winner accuracy uses all eligible official finals; Brier and Over metrics use only matched valid frozen forecasts. A minimum 30-game genuinely prospective cohort with at least 27 correct winners is necessary for the stated numerical 90% milestone, but is not sufficient to prove sustained predictive superiority.

## V32 (October 27, 2026): exact matched-game winner uncertainty

The read-only report now includes **exact two-sided McNemar tests** for original vs simple Elo, original vs fixed V23, and Elo vs V23, using precisely the same valid frozen games and outcomes as the matched winner/Brier comparisons. Each comparison reports the number of games only one model predicted correctly, the total discordant games, and the exact binomial p-value. Zero discordant games correctly yields p=1; tiny samples do not imply superiority. The test does **not** select or tune any winner model, does not use 2026 results for training, does not change the frozen joint simulation odds, and is **not** a model-promotion criterion. The full-cohort denominator still includes every missed original forecast. Older-year 2020–2025 baselines and the original 90% gate are unchanged.

## V33 (October 28, 2026): independent official team identity

The read-only grader now requires the official MLB schedule to provide distinct home/away team names and requires each saved original's frozen `home_name` and `away_name` to match the corresponding official names. Conflicting duplicate official finals (including team IDs/names) fail closed. A missing, swapped, or incorrectly labeled forecast remains in the **full official denominator as incorrect**, rather than being evaluated against the wrong home-win outcome. This is an integrity guard, not a 2026-trained model change. Existing genuine same-simulation winner-plus-Over odds and old original files are untouched.

## V34: Frozen Over-probability and joint-coverage audit (October 29, 2026)

For each verified original, the independent read-only evaluator now requires the **published** frozen `total_line_probabilities` Over and Under 4.5/5.5 probabilities to match the probabilities implied by the **same saved simulation** `total_distribution` (absolute tolerance 1e-6). The simulated distribution must have nonnegative run counts and total probability one. This prevents a scorecard from silently grading an internally reconstructed probability that differs from the forecast actually displayed before first pitch.

The report explicitly records `valid_frozen_total_forecasts`, `invalid_total_forecasts` (with game IDs and reasons), and per-threshold `missing_or_invalid_joint_ids`. A missing or inconsistent total/joint forecast is **not imputed**, and the game remains in the complete official winner denominator. The original, Elo, and V23 winner probabilities and all stored records remain untouched.

This is a **data-integrity/coverage improvement**, not a fitted forecasting model or a claim of increased winner accuracy. The 2020–2025 historical baseline, strictly prospective first-commit checks, and genuine same-simulation joint odds are unchanged.
